# Definition of Done

A task is done when:

- contract/spec matched;
- happy and unhappy paths tested;
- stable errors used;
- no broad capability added;
- no raw shell command;
- TypeScript/Rust checks pass;
- docs updated;
- no private paths/debug artefacts committed.

MVP is done when:

- all Must requirements work;
- acceptance scenarios pass or have explicit waiver;
- Windows packaged smoke passes;
- fixture/golden tests pass;
- restart/relink works;
- cancel leaves no false final;
- offline operation passes;
- notices/known limitations exist.

“One FFmpeg command worked once” is not the definition of done.
